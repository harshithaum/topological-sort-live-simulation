Decrease & Conquer.

Topological sorting on a directed acyclic graph

Claim A topological order exists iff G is a DAG

(⇒) Order exists ⇒ no cycles. Suppose a topological order exists but G contains a cycle v1→v2→…→vk→v1. In any linear ordering consistent with the edges, v1 must precede v2, which must precede v3, …, which must precede v1 — forcing v1 to precede itself. Contradiction. So a graph with a topological order has no directed cycle, i.e. it is a DAG.

(⇐) DAG ⇒ order exists. Induct on |V|. A nonempty finite DAG always has at least one source (in-degree 0): walk backward along incoming edges from any vertex; since the graph is finite and acyclic this walk cannot revisit a vertex, so it must terminate at a vertex with no incoming edge. Remove that source s: the remaining graph G−s is still a DAG (a subgraph of a DAG has no cycle either), so by the induction hypothesis it has a topological order. Prepending s yields a valid topological order of G. Base case |V|=0 is vacuous. ∎

Efficiency Both algorithms run in Θ(|V| + |E|)

DFS-based. Every vertex is colored WHITE→GRAY→BLACK exactly once (Θ(V) work), and the adjacency list of every vertex is scanned exactly once across the whole traversal, so every edge is examined exactly once (Θ(E) work). Pushing a finished vertex onto the output list is O(1). Total: Θ(V + E), i.e. linear in the size of the graph.

Source-removal (Kahn's). Computing in-degrees is one pass over all edges: Θ(E). Each vertex enters and leaves the queue exactly once: Θ(V). Each edge is relaxed (in-degree decremented) exactly once when its tail is dequeued: Θ(E). Total: Θ(V + E) as well — identical asymptotic class, different constant-factor bookkeeping (a queue instead of the implicit recursion stack).
